# HRS Food Insecurity and Psychological Health

This repository contains the R code used for the analyses reported in the manuscript:

**Socioeconomic Differences of Psychological Health and the Potential Benefit of Eliminating Food Insecurity: Longitudinal and Counterfactual Evidence from the Health and Retirement Study**

## Data source

This study used publicly released data from the Health and Retirement Study (HRS), including the 2013 Health Care and Nutrition Study (HCNS) and relevant HRS Core Interview waves.

Participant-level HRS data are not included in this repository because access to HRS data is subject to the HRS Conditions of Use. Researchers wishing to reproduce the analyses should obtain the required data directly from the Health and Retirement Study.

## Code

The complete statistical analysis code is provided in:

`analysis.R`

The script includes data preparation, variable construction, descriptive analyses, longitudinal models, modified Poisson regression, counterfactual analyses, inverse-probability-of-observation weighting sensitivity analyses, and generation of the main analytical results.

## Software

All analyses were conducted in R.

## Data availability

No participant-level HRS data are redistributed through this repository. Access to the original HRS data is available to registered users through the Health and Retirement Study data portal.
